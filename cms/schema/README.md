# Схема данных CMS

`content-model.json` — независимый от конкретной базы контракт первой версии. Он фиксирует коллекции, поля, связи, перечисления и медицинские ограничения до применения изменений в Directus.

Проверка:

```powershell
node .\cms\scripts\validate-model.mjs .\cms\schema\content-model.json
node --test .\cms\tests\content-model.test.mjs
```

## Связь с Directus

После первого запуска тестового экземпляра из контракта создаётся схема Directus. Полученный снимок сохраняется как `directus-schema.yaml` и повторно применяется к чистой тестовой базе. В Git не сохраняются пользователи, пароли, токены, лицензионный ключ, коды 2FA и фактические медицинские подтверждения.

`content-model.json` остаётся смысловым контрактом, а `directus-schema.yaml` станет техническим снимком реализации. Изменение технического снимка без соответствующего изменения контракта и тестов не принимается.

## Публичные и внутренние поля

Поля с `public: true` могут попасть в снимок выпуска. Поля с `reviewed: true` входят в проверяемый медицинский набор. Внутренние назначения, комментарии и доказательства согласия в публичный снимок не входят.

Формат `sanitized_rich_text` означает ограниченный редактор и обязательную санитарную обработку при экспорте. Произвольные HTML, JavaScript, импорты MDX и компоненты из CMS не исполняются.
