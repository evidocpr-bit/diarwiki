# Закрытый предпросмотр ДиарВики

Предпросмотр — отдельная статическая сборка. Он не добавляет динамические маршруты в рабочий сайт и не меняет активный выпуск.

## Поток доступа

1. Доверенная служба получает из CMS нормализованные данные выбранной версии и создаёт `preview.json`.
2. `create-preview.mjs` собирает копию Astro-сайта с `noindex`, `no-referrer` и отключённой аналитикой.
3. В каталог `/srv/diarwiki-previews/p/<preview-id>` атомарно помещается только готовая сборка.
4. Пользователь открывает одноразовую подписанную ссылку `/access?...`.
5. Служба проверяет HMAC и срок, записывает `Secure; HttpOnly; SameSite=Strict` cookie и перенаправляет на `/` без токена в адресе.
6. Caddy проверяет cookie через `forward_auth`, получает внутренний `X-Preview-Id` и обслуживает соответствующий каталог.

Подпись не попадает в HTML, журнал сборки или статические файлы. Caddy не отправляет внутренний заголовок клиенту. Сборка не подключает Яндекс Метрику и запрещает внешние ресурсы политикой CSP.

## Создание

```powershell
$env:DIARWIKI_PREVIEW_SECRET = '<минимум 32 случайных байта>'
$env:DIARWIKI_PREVIEW_ORIGIN = 'https://preview.diarwiki.ru'
node .\cms\preview\create-preview.mjs `
  --input .\working\preview.json `
  --site .\site `
  --workspace . `
  --root C:\srv\diarwiki-previews `
  --ttl-seconds 3600
```

Максимальный срок — 24 часа. Повторное использование того же `preview_id` запрещено.

## Очистка

`diarwiki-preview-cleanup.timer` запускает очистку каждые 15 минут. Удаляются только каталоги с корректным идентификатором и истёкшей мета-записью; символические ссылки и пути вне корня приводят к остановке.

`Caddyfile.preview` подключается к основной конфигурации Caddy после создания DNS-записи и TLS. До этого служба может проверяться на закрытом тестовом адресе.
