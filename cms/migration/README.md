# Миграция действующего сайта в CMS

Сценарии читают текущие MDX-материалы, реестр источников, библиотеку, служебные страницы, навигацию и настройки сайта. Результат записывается в проверяемый пакет до подключения Directus. Публичный сайт при этом не переключается.

## Подготовить пакет

```powershell
node .\cms\migration\import-current-content.mjs `
  --workspace . `
  --output .\working\cms_migration `
  --source-commit <полный-git-commit>
```

Создаются:

- `migration-bundle.json` — записи коллекций и список локальных файлов для загрузки;
- `migration-report.json` — машинная проверка ссылок, идентификаторов и блокирующих условий;
- `migration-report.md` — краткий отчёт для человека.

Стабильные идентификаторы выводятся из существующих `contentId`, `source id`, `LIB-*`, slug и путей медиа. Повторная подготовка того же содержимого создаёт те же идентификаторы. Произвольный JavaScript из MDX не выполняется: допускаются только литералы строк, чисел, массивов и объектов, необходимые существующим компонентам.

Медицинская отметка переносится только при полном наборе фактических данных о рецензии и отпечатке версии. У текущих материалов такой подтверждённой записи нет, поэтому они остаются со статусом `pending`. Права на иллюстрации также остаются `pending` до документального подтверждения владельцем.

## Загрузить в пустой тестовый Directus

Сначала применяются техническая схема и политики CMS. Затем задаются переменные только в текущем процессе и запускается импорт:

```powershell
$env:DIRECTUS_URL = 'http://127.0.0.1:8055'
$env:DIRECTUS_STATIC_TOKEN = '<временный-токен-владельца>'
node .\cms\migration\apply-bundle.mjs `
  --bundle .\working\cms_migration\migration-bundle.json `
  --workspace . `
  --confirm-empty
```

Импорт откажется работать, если хотя бы одна целевая коллекция не пуста. При ошибке удаляются только записи и файлы, созданные текущим запуском. Флаг `--keep-partial` предназначен только для диагностики тестового окружения.

Токен, адрес с учётными данными и содержимое переменных окружения в отчёты не записываются.
