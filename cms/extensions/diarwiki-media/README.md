# DiarWiki Media Guard

Серверная проверка файлов, которые используются в материалах DiarWiki.

## Уровни защиты

1. Directus ограничивает размер загрузки 20 МБ и принимает только JPEG, PNG, WebP, GIF, SVG и PDF.
2. При создании `media_metadata` расширение читает файл из локального хранилища, сверяет MIME, расширение и сигнатуру, размеры изображения и вычисляет SHA-256.
3. Для SVG запрещены DOCTYPE/ENTITY, сценарии, обработчики событий, активные HTML-элементы, внешние ссылки и опасный CSS.
4. Без альтернативного текста, автора или источника и основания использования запись не создаётся.
5. Только `security_status=passed` может быть включён в снимок выпуска.

Directus 12 завершает физическую загрузку до события расширения. Поэтому неподходящий файл может временно остаться в закрытом хранилище, но не получает проверенную запись и не может попасть на публичный сайт. Периодический аудит выявляет такие файлы; автоматическое удаление намеренно не выполняется.

## Проверка и сборка

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm run typecheck
pnpm run build
```

## Полный аудит

```powershell
$env:DIRECTUS_MEDIA_AUDIT_TOKEN = 'временный-служебный-токен'
node .\cms\scripts\media-audit.mjs --url http://127.0.0.1:8055 --uploads .\cms\uploads
node .\cms\scripts\media-audit.mjs --apply --url http://127.0.0.1:8055 --uploads .\cms\uploads
Remove-Item Env:DIRECTUS_MEDIA_AUDIT_TOKEN
```

Первая команда только читает и выводит итог без содержимого файлов и токена. Вторая обновляет SHA-256 и состояние проверки существующих записей. Файлы без `media_metadata` считаются непубличными и учитываются отдельным числом.
