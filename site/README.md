# ДиарВики

Статический MVP на Astro и Starlight. Опубликованные материалы находятся в `src/content/docs`, источники — в `src/content/sources`, публичные страницы — в `src/pages`.

## Локальная работа

```text
pnpm install
pnpm dev
pnpm test
pnpm test:e2e
pnpm build
```

Скопируйте `.env.example` в `.env` и укажите только реально работающий адрес редакции. `PUBLIC_SITE_INDEXABLE=true` используется исключительно для проверенной публичной сборки.

## Контентный контракт

Страницы получают список материалов через `src/lib/content/ContentRepository`. Текущий адаптер читает Astro Content Collections. Будущая база данных или CMS должна реализовать тот же контракт и сохранить `contentId` и публичные URL.

## Адреса и сведения о проекте

Название, основной домен, экспертное партнёрство с «Эвидок», данные куратора и реестр служебных страниц находятся в `src/config/site.ts`. Шапка, подвал, главная и страница «О проекте» читают повторяемые сведения из этого файла.

Полная информация о проекте публикуется только по адресу `/about/`. На главной остаётся краткий блок со ссылкой на эту страницу. Параметры вида `?v=...` не используются для показа новой версии.

Сборка проверяет статусы врачебной рецензии, записи подтверждений, канонические адреса, внутренние ссылки, русское название и отсутствие служебных параметров. Для статуса `reviewed` обязательны имя специалиста, специальность, дата, хэш версии и согласованная запись `review-records/<contentId>.json`. После реальной рецензии вычислите хэш командой `pnpm review:hash -- src/content/docs/knowledge/имя-файла.mdx`. Переносы строк CRLF/LF нормализуются, а `.gitattributes` фиксирует MD/MDX в LF. Изменение текста или метаданных после проверки блокирует сборку. Изменение изображения, общего источника или иной зависимости требует снять отметку вручную до повторной проверки. Журнал проекта не доказывает подлинность согласия: оригинал хранится отдельно, а владелец репозитория должен одобрять изменение статуса `reviewed`. Материал высокого риска нельзя публиковать без медицинской рецензии.

Статус показа Telegram-ссылок задаётся колонкой `public_link_status` в `library/catalog.csv`. Публикации «Diabet NEWS» (LIB-012–016) скрыты до согласования ссылки с правообладателем, приглашение в закрытую группу (LIB-036) — до согласования с администраторами. Для статей доступны официальные страницы, DOI или издательские ссылки.

Сборка создаёт `/release.json` и проверяет внутренние ссылки. HTML и `/pagefind/*` не кешируются как неизменяемые, поскольку имена файлов Pagefind стабильные; `/_astro/*` разрешено кешировать с `immutable`. Caddy должен разрешать Pagefind запуск WebAssembly через `'wasm-unsafe-eval'`.

Правовые страницы пока требуют проверки профильным юристом и дополнения фактическими сведениями о месте нахождения оператора, инфраструктуре и сроках хранения технических журналов. Не публикуйте выпуск до закрытия этих пунктов.

## Безопасность

Не помещайте в репозиторий пароли, приватные SSH-ключи, медицинские документы и пользовательские показатели. Видео хранится на внешней платформе и встраивается только через отдельный компонент с загрузкой после клика.
