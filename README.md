# ДиарВики

[Сайт diarwiki.ru](https://diarwiki.ru) · [Исходники сайта](site) · [Правила участия](CONTRIBUTING.md)

Русскоязычная база знаний о жизни с диабетом: материалы для знакомства с темой, инструкции по устройствам мониторинга, библиотека источников, каталог сообществ и конвертер единиц глюкозы.

Проект развивается как просветительский ресурс. Статьи и пользовательский опыт не заменяют консультацию врача. Статус `medicalReview: pending` означает, что медицинская рецензия ещё не завершена; он не равнозначен проверке специалистом.

## Что входит в репозиторий

| Каталог | Содержимое |
| --- | --- |
| `site/` | Сайт на Astro, Starlight и TypeScript, MDX-статьи, компоненты, стили и изображения |
| `site/src/content/docs/` | Материалы базы знаний |
| `site/src/content/sources/` | Источники для статей |
| `library/` | Каталог ресурсов, публичные описания и каталог Telegram-сообществ |
| `site/tests/` | Модульные и браузерные тесты |
| `site/deploy/` | Сценарии выпуска, проверки и отката для сервера с Caddy |
| `cms/` | Подготовленная интеграция Directus: модель данных, роли, миграция, предпросмотр и выпуск |

Поиск работает через Pagefind. Итог сборки — статические файлы в `site/dist/`.

## Быстрый запуск

Используются Node.js 24 и pnpm 11.25.0. Версия pnpm закреплена в `site/package.json`, зависимости — в lock-файле.

```sh
git clone https://github.com/evidocpr-bit/diarwiki.git
cd diarwiki/site
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

Сайт откроется по адресу, который напечатает Astro. Обычно это `http://localhost:4321`.

Скопируйте `site/.env.example` в `site/.env`, если нужны собственные настройки. `PUBLIC_EDITOR_EMAIL` принимает действующий адрес редакции. `PUBLIC_SITE_INDEXABLE=false` оставляет тестовую сборку закрытой от индексации. Секреты в переменных с префиксом `PUBLIC_` хранить нельзя.

## Проверка и сборка

Команды выполняются из `site/`:

```sh
pnpm test
# PowerShell: $env:PUBLIC_SITE_INDEXABLE="true"
# bash: export PUBLIC_SITE_INDEXABLE=true
pnpm build
pnpm preview
```

Полная проверка sitemap рассчитана на сборку с `PUBLIC_SITE_INDEXABLE=true`. Этот флаг разрешает индексацию итоговых файлов, поэтому тестовый результат не следует размещать на публичном домене.

Сборка проверяет TypeScript/Astro, отметки медицинской рецензии, подтверждения рецензий, внутренние ссылки, канонические адреса и поисковый индекс.

Браузерные проверки:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

Проверки модулей CMS из корня репозитория:

```sh
node --test cms/tests/*.test.mjs
```

GitHub Actions запускает модульные тесты сайта, проверки CMS и сборку при push и pull request. Автоматического развёртывания на рабочий сервер нет.

## Редактирование материалов

Статьи находятся в `site/src/content/docs/`. Схемы контента и обязательные поля определены в `site/src/content.config.ts`. Повторяемые сведения о сайте и навигация — в `site/src/config/site.ts`.

Для статуса `reviewed` нужны сведения о специалисте, дата, хэш проверенной версии и согласованная запись в `site/review-records/`. Содержание нельзя объявлять проверенным только на основании наличия источников или прохождения автоматических тестов. Подробнее: [правила сайта](site/README.md) и [записи рецензий](site/review-records/README.md).

## Публикация сайта

Публичный репозиторий хранит исходники. Размещение на GitHub само по себе не обновляет `diarwiki.ru` и не включает GitHub Pages.

Для отдельного развёртывания используйте [инструкцию](site/deploy/README.md). Адрес сервера передаётся явно через `-HostName`; ключи SSH и рабочие настройки хранятся вне Git. Перед выпуском нужны проверка прав на материалы, фактических реквизитов и настроек сервера. Файлы подтверждения владения доменом и IndexNow добавляются отдельно владельцем при развёртывании.

CMS включена как подготовленная интеграция. Этот репозиторий не подтверждает её ввод в эксплуатацию: для этого отдельно проверяются сервер, резервное копирование и восстановление, доступы, лицензирование и права на изображения. Подробнее: [CMS](cms/README.md).

## Публичная копия и права

В репозиторий не входят архивы переписки, документы НИР/ВКР, пользовательские медицинские данные, локальные отчёты, `.env`, приватные ключи и история рабочего каталога. Из карточек библиотеки оставлены разделы для сайта; приглашения в закрытые группы и контакт модератора исключены. Карточки таких сообществ сохраняются без активных ссылок.

Публичность репозитория не означает свободную лицензию на все тексты, код, иллюстрации и товарные знаки. Общая лицензия пока не выбрана владельцем; права сторонних авторов сохраняются. Условия повторного использования нужно согласовать с правообладателями.
