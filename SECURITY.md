# Сообщение об уязвимости

Не публикуйте секреты, персональные сведения и способы доступа к рабочей инфраструктуре в Issues. Используйте [приватный отчёт GitHub](https://github.com/evidocpr-bit/diarwiki/security/advisories/new). Резервный канал — действующий контакт редакции на https://diarwiki.ru/about/.

Опишите затронутую часть проекта и способ воспроизведения на локальной копии. Не проверяйте уязвимости на данных других пользователей. Если случайно опубликован секрет, его нужно отозвать: удаления файла из текущей версии недостаточно.
